#  Brian Mutugi | Web Developer Portfolio

A responsive portfolio website that lists my projects and lets visitors send me a message.

## Built with

- HTML
- CSS (flexbox, responsive layout)
- JavaScript (projects rendered from an array, form validation)

## Features

- Projects list built from a JavaScript array, so adding a project takes one block of code
- Contact form with validation for name, email and message
- Mobile-friendly layout with working navigation links

## Run it locally

1. Download or clone this repository.
2. Open the folder in VS Code.
3. In the terminal, run `npx serve`.
4. Open the address it prints, usually `http://localhost:3000`.
